## 3. 分层启动

```bash
# 最小可运行
docker compose up -d postgis redis

# 追加中间件（镜像可拉取时）
docker compose --profile stream up -d     # Kafka
docker compose --profile tds up -d        # TDengine
docker compose --profile obj up -d        # MinIO + bucket 初始化
```

应用侧：

```bash
pnpm --filter @traffic/api seed    # 建表 + 灌数据（幂等，可重复执行）
pnpm dev:api
pnpm dev:web
```

带 Kafka/TDengine/MinIO 启动 API（Windows PowerShell）：

```powershell
$env:KAFKA_BROKERS = "localhost:9092"
$env:TDENGINE_URL  = "http://localhost:6041"
$env:MINIO_ENDPOINT = "localhost"
pnpm dev:api
```

启动日志会明确打印每个依赖的状态，例如：

```
[Kafka] 未配置 KAFKA_BROKERS，使用直接模式（无缓冲/无背压）
[TDengine] 未配置 TDENGINE_URL，过车记录降级为进程内环形缓冲（最近 500 条）
[RedisIoAdapter] Socket.IO 已挂载 Redis Adapter（多实例广播可用）
```

## 5. 排障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `/api/health` 里 `postgis: down` | 容器未起或端口占用 | `docker compose up -d postgis`；确认 5432 未被本机其它 PG 占用 |
| 接口 503「PostGIS 未连接」 | 未建表/未灌数据 | `pnpm --filter @traffic/api seed` |
| 地图全黑但右侧数据正常 | 相机被压到地下 / 渲染模式问题 | 访问 `/?diag=1` 看 `camHeight`；试 `/?render=overlay` |
| 车辆/光柱不可见 | 深度精度塌陷 | 确认实例材质 `depthTest: false`（见 `docs/01` §2.3） |
| `pnpm install` 报 corepack 404 | `packageManager` 锁版本 | 移除该字段或 `corepack disable` |
| `ERR_PNPM_IGNORED_BUILDS` | pnpm 拦截依赖 postinstall | 已在 `pnpm-workspace.yaml` 配 `onlyBuiltDependencies` + `strictDepBuilds: false` |
| `docker pull` 超时 | 镜像仓库不可达 | 用内网镜像仓库/离线包；Kafka/TDengine/MinIO 缺失时应用会自动降级 |
| 告警一直不出现 | 规则全部关闭或未注入过车 | 检查 `/api/surveillance/rules`，先点「模拟 20 辆过车」 |
